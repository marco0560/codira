## Shared failure and implementation

Captured libc++ scope wrappers depend on compiler markup, function-like
annotation aliases, computed pragma operands and the configured ABI namespace.
Previously those pieces could not compose into a complete parse.

The C++19 implementation now proves supported function annotation
replacements, pure stringifier pragma operands and compatible alternatives;
composes namespace wrappers and explicit identifier bindings in one source
projection; accepts explicitly configured `__1` and uppercase identifiers; and
normalizes equivalent namespace brace spacing. Macro-value calls that the
provider represents as initializer declarators are recognized under the same
replacement proof. Original source signatures, UTF-8 call columns and CRLF
positions remain covered by regression tests.

Unbound uppercase namespaces, undefinitions, cycles, incompatible alternatives,
late dependencies, arity failures, type/linkage changes and keyword overrides
remain held. This is bounded macro recovery, not conditional branch evaluation.
The distribution metadata advances the C++ plugin to 2.0.15 and the official
bundle to 2.0.40. No release or merge has been performed.

The explicit `_LIBCPP_ABI_NAMESPACE=__1` profile is supported by the checked-out
libc++ CMake defaults. It is a supplied analysis assumption, not a new universal
namespace default.
